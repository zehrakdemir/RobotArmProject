Path preview

    

      

        

          
Waiting for the robot…

          

            
            
            —
            
          

          

            Grey: the arm now. Blue: selected path. Red: rejected path. Green dot: target TCP.
            Axis triads (X red, Y green, Z blue): the long one at the base is the base frame
            (Base jog), the short one at the tool is the TCP frame (Tool jog) and turns with
            the tool. Floor grid at Z = 0. Drag to rotate, scroll to zoom.
          

        

        

          
No preview. Turn on “Preview before moving”, then use a jog button or Go.

          

          

          

          

            
            
          

          

            With Preview before moving on, the jog buttons and Go only plan the paths;
            the robot does not move. Select an option and press Run this path: the robot
            follows exactly the path shown. If the arm moves after planning, plan again.
            Saved moves and pick & place are not previewed.

Base frame, in millimetres. The release orientation is the
              same RX/RY/RZ as the grasp.

          

          

          

            
            
          

          
The object height comes from the detection; the fingertips go
            this many millimetres below the measured top face.

          

            
            
            
          

          
Each path is a full chain planned with a different arm
            configuration; planning more takes longer. They are listed shortest total joint
            travel first.

          

          

            
            
          

          

          

          

          

            The chain (approach → grip → lift → transfer → lower → release → retreat) is
            planned and shown in the 3D view above before anything moves. Collision check
            covers the robot, gripper and floor only — real objects on the table are not
            in the model.

          Jog the arm to where it should grip the object and save the pose. The arm
